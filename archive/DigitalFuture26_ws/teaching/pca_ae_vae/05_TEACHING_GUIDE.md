# 05 · 教學文件(老師視角)— 逐段講法 · 板書 · 比喻 · 計時

> 這是助教上課的**主腳本**。每一段都給:**要說什麼、要在白板畫什麼、學生會卡在哪、怎麼接住、
> 大約幾分鐘**。NN 與資料流動的關鍵節點標 ★,那是最該慢下來的地方。
> 原則:**每一段只引入一個新概念;每個概念先比喻、再圖、最後才程式。**

## 0. 開場(5 分鐘)— 立框架

**說**:「今天我們只做一件事——**把一筆很多數字的資料,壓成兩個數字,再還原回去**。能還原得越像,代表那兩個數字越精華。我們會用三種做法做同一件事:PCA、AE、VAE,一個比一個強。」

**板書**(整堂都留著):
```
   x (9個數字) ──[編碼]──▶ z (2個數字) ──[解碼]──▶ x̂ (9個數字)
                                                   目標:x̂ ≈ x
```

**說**:「全場記住這張圖。PCA、AE、VAE 都是這張圖,只差『編碼器怎麼做』跟『中間那團 z 長什麼樣』。」

> ⚠️ 別在開場解釋那 9 個數字是什麼城市意義——那是另一位老師的事。對我們,它就是「9 個數字」。

## 1. PCA(25 分鐘)— 在安全的線性世界建立語言

### 1.1 比喻先行(3 分)
**說**:「想像一群人站成一團。我要用一張**平面照片**抓住這群人的差異。從哪個角度拍,最能看出誰高誰矮、誰胖誰瘦?PCA 就是**自動幫你挑那個最好的拍照角度**。」

### 1.2 三個關鍵詞,寫上白板(5 分)
- **編碼 z = x·W**:把資料投影到新角度。
- **解碼 x̂ = z·Wᵀ**:從照片反推回原本。
- **重建誤差 = (x − x̂)²**:照片漏掉多少資訊。

**說**:「PCA 的編碼器跟解碼器是**同一個矩陣**(一個正著用、一個轉置用),所以它只能『直線』地壓。這是它的極限,也是等下 AE 要突破的點。」

### 1.3 ★ 為什麼要先標準化(5 分,務必講)
**示範**:「`gfa` 可以到二十萬,`coverage` 只有 0 到 1。如果不先拉到同一個尺度,PCA 會以為 gfa 最重要——其實它只是**單位大**,不是**真的重要**。」
**板書**:`每個 channel 各自 (x − 平均) / 標準差` → 全部變成「平均 0、散開 1」。
**學生常誤解**:以為標準化是「讓資料變好看」。→ 糾正:是「讓不同單位的特徵公平競爭」。

### 1.4 親手跑(10 分)
全班一起跑 `pca.py`。目標:**每個人都成功印出重建誤差、看到一張 2D 散點圖**。
**說**:「恭喜,你已經把 9 維壓成 2 維了。PCA 不用訓練、一步算完。接下來我們讓神經網路做同一件事,看能不能做得更好。」

## 2. AE(35 分鐘)— 第一次親手訓練神經網路

### 2.1 從 PCA 接過來(5 分)
**說**:「PCA 只能直線壓。但真實資料常常是**彎的**。我們把那個矩陣 `W` 換成一個**會彎曲的神經網路**,讓它自己學怎麼壓——這就是 Autoencoder。」
**板書**:在開場那張圖上,把「編碼」「解碼」各畫成一疊小方塊(層)。

### 2.2 ★ 神經網路在做什麼(8 分,核心)
**說**(配板書):「一層神經網路做兩件事:**乘一個矩陣(換組合)、過一個激活函數(掰彎)**。一層一層疊,就能描述很複雜的彎曲。」
```
9 個數字 → [32] → [16] → ★[2]★ → [16] → [32] → 9 個數字
                          ↑
                     瓶頸:只准留 2 個數字
```
**關鍵句**:「中間**只有 2 個神經元**,資料被迫擠過這個窄門。擠得過去又還原得回來,代表它真的抓到精華了。**這個窄門就是壓縮。**」

**學生常誤解**:
- 「層數越多越好?」→ 不一定,資料小會過擬合;夠用就好。
- 「瓶頸那層要不要 ReLU?」→ ★ 不要。latent 要能取負值,被 ReLU 砍掉就殘廢了。

### 2.3 ★ 訓練迴圈怎麼運作(8 分,務必講透)
**板書四步,反覆強調這是所有神經網路的心臟**:
```
1. 前向:x → 模型 → x̂            (做一次預測)
2. 算帳:loss = (x − x̂)²         (錯多少)
3. 反向:loss 對每個權重求梯度    (誰該負責、往哪調)
4. 更新:權重往減少 loss 的方向走一小步
   ↑ 重複幾萬次,loss 往下掉 = 模型在學
```
**比喻**:「像下山。loss 是高度,梯度是『最陡下坡方向』,lr(learning rate)是『一步跨多大』。跨太大會摔(NaN),跨太小走不到。」

### 2.4 親手跑(14 分)
- 給**完整可跑的程式**,只留 encoder/decoder 的層當 **TODO** 讓學生填。
- 按下訓練,**盯著 loss 往下掉**——這是學生第一次「看到模型在學」,很有感。
- 跑完畫 latent 散點。**和 PCA 的圖並排**:「AE 因為會彎,常常把資料攤得更開。」
- 卡住的人 → 把檔頂 `USE_PRETRAINED = True`,不要卡住全班。

## 3. VAE(45 分鐘)— 解鎖「生成」

> 這是整包的高潮,也是最容易講糊的地方。**慢。** 先講「為什麼 AE 不能生成」,動機到位了,VAE 的每個零件才有意義。

### 3.1 ★ 動機:為什麼 AE 不能生成(8 分,絕不能跳)
**示範**:「我們用 AE 的 latent 來生成新資料——隨便在 2D 平面點一個點,丟進 decoder。」
**結果**:常常解出垃圾。
**板書**:畫一個 2D 平面,真實資料的 latent 點**散落各處、中間一堆空洞**。
**關鍵句**:「AE 從沒被要求『把空間填滿、排整齊』。你點到**洞**裡,decoder 沒看過那裡,只能亂解。**所以 AE 會壓縮、不會生成。**」
**設問**:「那如果我們**強迫**所有資料的 latent 擠成一團整齊、沒有洞的雲呢?是不是隨便抓都抓得到合理的東西?」→ 這就是 VAE。

### 3.2 ★ VAE 的三個改動(配 04 文件,12 分)
**說**:「VAE 不是新模型,它就是 AE **加三樣東西**。」逐一在白板把 AE 的圖改掉:

**改動一:瓶頸不再吐一個點,而是吐一個『分布』。**
```
       …→ [16] ─┬─→ μ     (這團雲的中心)
                └─→ logσ²  (這團雲多散)
```
比喻:「AE 說『這筆資料在座標 (3,1)』。VAE 說『這筆資料**大概**在 (3,1) 附近,範圍這麼大』。它從一個點變成一小團霧。」

**★ 改動二:Reparameterization(重參數化)——全堂最難,放最慢(5 分)**
**先講問題**:「我們要從那團霧裡**抽**一個點 z。但『抽籤』這個動作是隨機的,**沒辦法回傳梯度**——模型學不到霧該畫多大、畫哪。」
**再講解法**(板書):
```
ε ~ N(0,1)      ← 先抽一個跟模型無關的標準亂數
z = μ + σ · ε   ← 再用它組出 z
```
比喻:「與其『直接抽一個會動的籤』,不如『先抽一個固定的亂數 ε,再用我能控制的 μ、σ 把它**搬**到該去的位置』。隨機性外包給 ε,μ 和 σ 就變回**可以求梯度的普通運算**,模型就學得動了。」
**關鍵句**:「**這一招叫重參數化。它是 VAE 唯一的魔術,沒有它 VAE 訓不起來。**」

**改動三:多一條 loss(KL)逼那團雲靠近『標準的雲』N(0,1)。**
```
總 loss = 重建誤差(要像)  +  β · KL(要整齊靠近原點)
```
比喻:「兩個力在拔河。**重建**想把不同資料推開、佔好佔滿;**KL**想把大家收攏成同一團標準雲。拔河的平衡點,就是**又有結構、又沒有洞**的漂亮 latent。」

### 3.3 ★ 為什麼這樣就能生成(5 分)
**板書**:在 2D 平面畫一團以原點為中心、漂亮的圓雲(對比 AE 那張破洞圖)。
**說**:「訓練完,所有真實資料的 latent 都被 KL 收進這團 N(0,1) 的雲。雲裡到處都合理,所以我**閉著眼睛從 N(0,1) 抽一個 z、丟進 decoder,就生出一筆全新但合理的資料**。這就是生成。」
```
z ~ N(0,1) → Decoder → 新資料   ← AE 做不到,VAE 做得到,差別只在那條 KL
```

### 3.4 親手跑 + 拉 β(15 分)
- 給好程式,讓學生**改 β**:β=1(預設)→ β=0.1 → β=5。
- 觀察:**β 小 → 重建清楚但生成爛(退回 AE);β 大 → 生成順但重建糊(雲擠成一點)。**
- **說**:「沒有完美的 β,這是一個**取捨**。你親手拉的,就是研究者每天在拉的旋鈕。」
- 卡住 → 載入 `pretrained/vae.pt`,確保每個人都看到「從亂數生成一筆資料」。

## 4. 收束(5 分鐘)— 把三個串成一條線

**板書最終總表**(留到下課):
```
PCA :  線性矩陣壓縮            不用訓練     不太能生成
AE  :  神經網路壓縮(會彎)    要訓練       不能生成(latent 有洞)
VAE :  AE + 分布 + 重參數 + KL  要訓練       能生成(latent 是整齊的雲)
```
**結語**:「**Encoder 給你分析**(把真實資料變成座標去研究),**Decoder 給你生成**(從座標長出新資料)。VAE 兩個都有——這就是它接到後面城市生成與分析的原因。技術部分到這裡;城市意義交給另一位老師。」

## 5. 學生常見問題 FAQ(口袋版)

| 學生問 | 一句話答 |
|---|---|
| latent 為什麼設 2 維? | 為了畫得出來;真正用會設 4~8。 |
| 為什麼瓶頸不能放 ReLU? | latent 要能取負值,ReLU 會砍掉一半。 |
| logσ² 為什麼取 log? | 讓網路自由輸出任意實數,exp 後保證 σ>0,數值穩。 |
| ε 是什麼?每次一樣嗎? | 每次重抽的標準亂數,讓抽樣可微、也讓同一筆資料 latent 有點抖動。 |
| KL 到底在罰什麼? | 罰「latent 不像標準常態」,逼它整齊好生成。 |
| β 要設多少? | 沒標準答案;這是重建 vs 生成的取捨,要自己試。 |
| 我訓練 loss 是 NaN! | lr 調小、對 logσ² 做 clamp(見 03 踩雷表)。 |
| AE 生成的東西好爛? | **正常**,這正是我們要證明「為什麼需要 VAE」。 |

## 7. 附錄:為什麼不教 GAN / Diffusion(被問到時的標準答覆)

「我們資料只有幾千筆 cell、24 個窗。GAN 和 Diffusion **非常吃資料、現場訓不完、也不穩**;而且 GAN **沒有 encoder**,沒辦法把真實城市映回 latent 去做分析。VAE 同時有 encoder(分析)和 decoder(生成)、小資料也訓得動、概念能一步步從 PCA 接上來——所以它是這堂課的終點。」
