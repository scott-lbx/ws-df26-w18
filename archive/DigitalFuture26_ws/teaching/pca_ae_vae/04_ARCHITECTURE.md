# 04 · 模型架構設計文件 — 每層尺寸、NN 內部、Loss

> 目的:把三個模型的「骨架尺寸 + 數學」寫死,讓助教備課時有唯一真相來源,
> 也讓學生填 TODO 時有對照。**含 reparameterization 與 KL 的完整推導(白話版)。**

共用:輸入維 `C=9`、latent 維 `L=2`、batch `B`。

---

## 1. PCA(沒有神經網路,但要會講它是「線性 AE」)

**架構**:就是一個矩陣 `W ∈ ℝ^[9, 2]`。
- 編碼:`z = (x − x̄) · W`,`[B,9]·[9,2] → [B,2]`
- 解碼:`x̂ = z · Wᵀ + x̄`,`[B,2]·[2,9] → [B,9]`
- `W` 的兩行是「資料變異最大的兩個正交方向」,由對標準化後資料做 SVD 得到。

**為什麼它是 AE 的特例**:把 AE 的編碼器/解碼器都設成「單層線性、無激活、權重綁定(decoder=encoderᵀ)、要求正交」,AE 就退化成 PCA。→ **PCA = 受限的線性 AE**。這句話是 PCA→AE 的橋。

**目標函數**:最小化重建誤差 `‖X − X̂‖²`(等價於最大化保留變異)。閉式解,不用梯度下降。

---

## 2. AE(MLP 版)

### 2.1 架構(逐層)

```
Encoder                          Decoder
─────────────────                ─────────────────
Linear(9  → 32)                  Linear(2  → 16)
ReLU                             ReLU
Linear(32 → 16)                  Linear(16 → 32)
ReLU                             ReLU
Linear(16 → 2)   ← latent z      Linear(32 → 9)   ← 重建 x̂
```

| 設計選擇 | 值 | 理由 |
|---|---|---|
| 隱藏層寬度 | 32, 16 | 比輸入(9)稍寬再收斂,給網路一點容量;不用太大,資料量小 |
| latent 維 | 2 | 為了能畫成散點圖;真正應用可 4~8 |
| 激活 | ReLU | 簡單、好教、夠用 |
| 瓶頸層激活 | **無(線性)** | latent 要能取任意實數值,別被 ReLU 砍成非負 |
| 輸出層激活 | **無(線性)** | 目標是標準化後的實數(可正可負),不要 sigmoid |

### 2.2 Loss
```
L = MSE(x, x̂) = mean( (x − x̂)² )          ← 一個純量
```
- 連續特徵 → 用 **MSE**。(若輸入是 0/1 影像才用 BCE,本資料不是。)

### 2.3 訓練設定(建議預設)
- optimizer:Adam,lr = 1e-3
- batch:256
- epoch:50~100(資料小,很快)
- 切 train/val 看 val 重建誤差,避免過擬合

## 3. VAE(MLP 版)—— 重點

### 3.1 架構

```
Encoder body                     Heads                  Decoder
──────────────                   ────────               ─────────────────
Linear(9  → 32)                  Linear(16 → 2) → μ      Linear(2  → 16)
ReLU                             Linear(16 → 2) → logσ²  ReLU
Linear(32 → 16)                                          Linear(16 → 32)
ReLU                                                     ReLU
                                                         Linear(32 → 9) → x̂
```

- Encoder body 跟 AE 一樣,**只是最後不直接吐 z,而是吐兩個東西**:`μ`(中心)和 `logσ²`(散開度)。
- 兩個 head 是**並排**的兩個 `Linear(16→2)`,吃同一個 `h[B,16]`。
- Decoder 跟 AE 的 decoder 完全一樣。

### 3.2 Reparameterization(重參數化)— 全包最該講清楚的一段

**我們想做的事**:從 `N(μ, σ²)` 抽一個 `z`。

**問題**:「抽樣」是隨機操作,**沒有梯度**,反向傳播走不過去,μ、σ 學不到。

**解法**:把隨機性「搬到旁邊」。等價地寫成:
```
ε ~ N(0, I)                              ← 隨機,但與模型參數無關(外來常數)
σ = exp(0.5 · logσ²)                     ← 由 logσ² 算出標準差(保證為正)
z = μ + σ · ε
```
- 現在 `z` 是 `μ, σ` 的**可微函數** + 一個外來常數 `ε`。
- 梯度可以從 `z` 順著 `μ` 和 `σ` 流回 encoder。**抽樣照樣抽,但模型學得動了。**
- 程式:`z = mu + torch.exp(0.5*logvar) * torch.randn_like(mu)`

**為什麼輸出 `logσ²` 而不是 `σ`**:網路輸出可正可負的任意實數很自然;但 σ 必須 > 0。讓網路輸出 `logσ²`(任意實數),再 `exp` 變正數,既自由又安全,數值也穩。

### 3.3 Loss = 重建 + KL

```
L = MSE(x, x̂)  +  β · D_KL( N(μ,σ²) ‖ N(0,I) )
     └─ 重建項 ─┘     └──────── 整齊項 ────────┘
```

**KL 項的封閉公式(逐維加總,L=2):**
```
D_KL = 0.5 · Σ_j ( μ_j²  +  σ_j²  −  logσ_j²  −  1 )
     = 0.5 · Σ_j ( μ_j²  +  exp(logσ²_j)  −  logσ²_j  −  1 )
```
程式:`kl = -0.5 * torch.sum(1 + logvar - mu.pow(2) - logvar.exp(), dim=1).mean()`

**兩項在拉鋸(這是 VAE 的靈魂)**:
- **重建項**要 latent 帶足夠資訊 → 想把不同資料推到 latent 不同位置(攤開)。
- **KL 項**要每筆資料的 (μ,σ) 靠近 N(0,I) → 想把大家收回原點、σ 收到 1(收攏)。
- 兩者平衡的結果:latent **既有結構又平滑無洞** → 所以能從 N(0,I) 抽樣生成。

**β 的作用**:
- β 大 → 太整齊,重建糊(極端時 posterior collapse,latent 沒用)。
- β 小 → 重建好,但 latent 有洞,生成差(退化回 AE)。
- 教學就讓學生**親手拉 β**,看「重建清晰度 ↔ 生成合理度」的取捨。建議起點 β=1,再示範 0.1 與 5。

### 3.4 生成(只用 decoder)
```
z ~ N(0, I)  [m, 2]   →  Decoder  →  x̂ [m, 9]  →  反標準化  →  新資料
```

## 4. 三個模型的「差異」一頁總結(可當板書)

| | 編碼器 | 瓶頸輸出 | 額外損失 | 能生成 | 一句話 |
|---|---|---|---|---|---|
| **PCA** | 線性矩陣 W | z(1 個點) | 無 | 勉強 | 線性、閉式、不訓練 |
| **AE** | MLP | z(1 個點) | 無 | ❌ | 非線性壓縮,latent 有洞 |
| **VAE** | MLP + 兩個 head | μ, σ(一個分布)→ 抽 z | **+ β·KL** | ✅ | 把 latent 逼成平滑常態雲 |

> 從 AE 到 VAE 的全部改動只有三點:**(1) 瓶頸吐 μ/logσ² 兩個頭、(2) reparameterization 抽 z、(3) loss 多一個 KL。** 其餘(decoder、訓練迴圈、MSE)一字不改。把這三點圈起來,就是整堂 VAE 的精華。

## 5. 影像版(conv)架構(進階補充)

輸入 `[B, 9, 20, 20]`:
```
Encoder:  Conv(9→32, s2) → Conv(32→64, s2) → flatten[B,1600] → μ,logσ² 各 Linear(1600→L)
Decoder:  Linear(L→1600) → reshape[B,64,5,5] → ConvT(64→32, s2) → ConvT(32→9, s2) → [B,9,20,20]
```
- reparameterization、KL、loss 與 MLP 版**完全相同**,只有 encoder/decoder 內部換成卷積。
- ⚠️ 24 窗太少 → 切 patch + 8 向增強。主線仍建議用向量版教,conv 當延伸。
