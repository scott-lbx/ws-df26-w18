# 02 · 資料流程文件 — 每一步的 shape 與意義

> 目的:把資料從「磁碟上的表格」一路追到「latent」再「重建回來」,
> **每一個箭頭都標清楚 shape、為什麼是這個 shape、這一步在做什麼**。
> 助教被學生問「這裡為什麼是這個形狀」時,答案全在這份。

全包共用:`N=5785`(樣本數)、`C=9`(channel)、`L=2`(latent 維)、batch `B=256`。

---

## 0. 形狀符號速查

| 寫法 | 意思 |
|---|---|
| `[N, C]` | N 列、每列 C 個數字的矩陣(N 筆樣本,每筆 C 維) |
| `[B, C]` | 一個 batch:B 筆樣本 |
| `[B, 9, 20, 20]` | 影像版:B 張圖,每張 9 個 channel、20×20 像素 |
| 維度第一軸通常是「樣本/batch」,**訓練時永遠有 batch 軸** | |

---

## 1. 原始資料 → 模型輸入張量

### 1.1 從表格到矩陣

```
cells.parquet  (9600 列 × 多欄)
   │  ① 取 9 個 channel 欄位
   │  ② 丟掉空 cell(coverage < 0.02)
   ▼
X_raw   shape = [5785, 9]      ← N 筆樣本,每筆 9 維。這就是「原始輸入矩陣」
```

- **為什麼丟空 cell**:空 cell 全是 0,塞進去只會教模型「世界大多是空的」,稀釋訊號。
- **一列 = 一個 cell = 一筆訓練樣本**。模型一次看一列(或一個 batch 的列)。

9 個 channel 與其原始範圍(來自實際資料):

| idx | channel | min | max | 說明(技術線只需知道「數字尺度差很多」) |
|---|---|---|---|---|
| 0 | gfa | 100 | 215376 | 尺度極大 |
| 1 | coverage | 0.02 | 1.0 | 0–1 |
| 2 | mean_h | 6.2 | 338 | 中尺度 |
| 3–7 | sh_house/slab/tower/large/mid | 0 | 1 | 比例 |
| 8 | dom_sem_share | 0 | 1 | 比例 |

### 1.2 標準化(極重要,不做會壞)

```
X_raw [5785, 9]
   │  z-score:每個 channel 各自  (x - mean) / std
   ▼
X     [5785, 9]   ← 每個 channel 現在 mean≈0, std≈1
```

- **為什麼必做**:`gfa` 動輒上萬、`coverage` 只有 0~1。不標準化,PCA 會以為「gfa 最重要」(其實只是單位大),神經網路的梯度也會被大數值主宰。
- **mean / std 要存起來**:之後重建出來的 `x̂` 要 **反標準化** 才看得懂;新資料也要用**同一組** mean/std。
- 標準化是**逐 channel**,不是逐樣本。

> ⚠️ 鐵律:mean/std **只能用訓練資料算**,再套用到驗證/新資料。否則洩漏。

## 2. PCA 的資料流(線性、無訓練)

```
X [N, 9]
  │ ① 置中(減 mean,已在標準化做掉)
  │ ② SVD / 特徵分解,得主軸矩陣 W
  ▼
W  [9, 2]                ← 9 維空間裡挑出的 2 條「最大變異方向」
  │ ③ 投影  z = X · W
  ▼
Z  [N, 2]                ← 每筆資料的 2 維座標(latent / 主成分分數)
  │ ④ 重建  x̂ = z · Wᵀ
  ▼
X̂  [N, 9]               ← 從 2 維還原回 9 維
```

| 物件 | shape | 意義 |
|---|---|---|
| `W` | `[9, 2]` | 編碼器(就是個矩陣)。每一**行**是一條主軸 |
| `Z` | `[N, 2]` | 壓縮結果。`Z` 第 i 列 = 第 i 筆資料的精華座標 |
| `X̂` | `[N, 9]` | 重建。與 `X` 比較得「重建誤差」 |
| 重建誤差 | 純量 | `mean((X − X̂)²)`,越小越好 |

**一句話**:PCA 的「編碼器」與「解碼器」是**同一個矩陣 W 和它的轉置 Wᵀ**,所以一定線性、一定對稱。

---

## 3. AE 的資料流(神經網路,要訓練)

把 PCA 的「矩陣 W」換成「會彎曲的神經網路」。訓練時走 batch。

```
一個 batch:  x  [B, 9]
   │  Encoder(MLP)
   │     9 ──Linear→ 32 ──ReLU→ 16 ──ReLU→ 2
   ▼
   z  [B, 2]                    ← 這個 batch 的 latent
   │  Decoder(MLP)
   │     2 ──Linear→ 16 ──ReLU→ 32 ──ReLU→ 9
   ▼
   x̂  [B, 9]                   ← 重建
   │  loss = MSE(x, x̂)         ← 一個純量
   ▼
   反向傳播,更新 Encoder+Decoder 權重
```

逐層 shape(batch=256):

| 步驟 | 進 | 出 | 這層在做什麼 |
|---|---|---|---|
| Encoder L1 | `[256, 9]` | `[256, 32]` | 升維、找特徵組合 |
| Encoder L2 | `[256, 32]` | `[256, 16]` | 繼續壓 |
| Encoder L3 | `[256, 16]` | `[256, 2]` | **壓到瓶頸(latent)** |
| Decoder L1 | `[256, 2]` | `[256, 16]` | 開始還原 |
| Decoder L2 | `[256, 16]` | `[256, 32]` | |
| Decoder L3 | `[256, 32]` | `[256, 9]` | **還原回 9 維** |

- **瓶頸(bottleneck)= 那層只有 2 個神經元**。逼資料擠過 2 維,模型才被迫只留精華 → 這就是「壓縮」的物理來源。
- 跟 PCA 唯一差別:中間多了 ReLU(非線性),所以編碼器可以是「彎的」,能描述 PCA 的直線描述不了的結構。

---

## 4. VAE 的資料流(AE + 機率 + 抽樣)

VAE 在瓶頸處不再輸出一個點,而是輸出**一個常態分布的參數**(平均 μ 與對數變異 logσ²),再**抽樣**得到 z。

```
一個 batch:  x  [B, 9]
   │  Encoder body:  9 → 32 → 16
   ▼
   h  [B, 16]
   │  分兩個頭(各一個 Linear: 16 → 2)
   ├──▶ μ      [B, 2]      ← latent 的「中心」
   └──▶ logσ²  [B, 2]      ← latent 的「散開程度」(用 log 保證正)
   │
   │  ★ Reparameterization(重參數化):
   │     ε ~ N(0, I)        ε shape = [B, 2]   ← 標準常態雜訊
   │     z = μ + exp(0.5·logσ²) · ε
   ▼
   z  [B, 2]               ← 抽樣得到的 latent(每次略有不同)
   │  Decoder:  2 → 16 → 32 → 9
   ▼
   x̂  [B, 9]
   │  loss = MSE(x, x̂)  +  β · KL(N(μ,σ²) ‖ N(0,I))
   ▼
   反向傳播
```

逐物件 shape:

| 物件 | shape | 意義 | 學生最常卡在這 |
|---|---|---|---|
| `μ` | `[B, 2]` | 這筆資料 latent 的中心位置 | — |
| `logσ²` | `[B, 2]` | 不確定性/散開度(取 log 是為了讓網路自由輸出任意實數,再 exp 變正數) | 「為什麼是 log」 |
| `ε` | `[B, 2]` | 從 N(0,I) 抽的隨機雜訊 | 「雜訊哪來的」 |
| `z` | `[B, 2]` | = μ + σ·ε。**隨機**,所以同一個 x 每次 z 不同 | 「為什麼要隨機」 |
| KL | 純量 | 逼 (μ,σ) 這個分布靠近 N(0,I) 的「整齊度罰款」 | 「KL 是什麼」 |

**★ Reparameterization 為什麼非做不可(一句話版,細節見 04):**
「抽樣」這個動作沒辦法做反向傳播(隨機沒有梯度)。把隨機性外包給一個與參數無關的 ε,公式 `z = μ + σ·ε` 就變成「μ、σ 的可微函數 + 一個外來常數 ε」,梯度就能順著 μ、σ 流回 encoder。**這是 VAE 能訓練的關鍵機關。**

---

## 5. 生成階段的資料流(只有 VAE 有)

訓練完、把 encoder 丟一邊,只用 decoder:

```
從 N(0, I) 抽   z  [m, 2]        ← 想生成 m 筆,就抽 m 個點
   │  Decoder
   ▼
x̂  [m, 9]                       ← m 筆全新(標準化空間的)資料
   │  反標準化(× std + mean)
   ▼
新資料  [m, 9]                   ← 還原回原始尺度,可交給生成線老師渲染
```

- **為什麼從 N(0,I) 抽就有效**:因為訓練時 KL 已經把所有真實資料的 latent **逼進 N(0,I) 這團雲**。雲裡到處都是「合理」的點,所以亂抽也解得出合理結果。
- 對照:AE 沒有 KL,latent 散落各處、中間是洞,從 N(0,I) 亂抽會掉進洞 → 解出垃圾。**這就是 VAE 能生成、AE 不能的全部原因。**

## 6. 影像版(conv 變體)的 shape ——用整張 grid 當一張圖

若不把 cell 拆開、而是把**整個 20×20 窗當一張 9-channel 影像**:

```
輸入  [B, 9, 20, 20]
   │  Conv 下採樣
   ▼  [B, 32, 10, 10]
   ▼  [B, 64, 5, 5]
   │  flatten → [B, 1600] → 兩個頭 → μ,logσ² [B, L]
   ▼  z [B, L]
   │  反卷積上採樣(ConvTranspose)
   ▼  [B, 9, 20, 20]   重建
```

- 用途:當你要保留「鄰里的空間排列」而不只是逐格統計時。
- ⚠️ 樣本只有 24 窗 → **必須切 patch + 旋轉翻轉增強**,否則樣本太少。
- 教學主線建議仍用 §3/§4 的向量版(shape 單純、好追);conv 版當進階補充。

## 7. 一頁總表(把全部 shape 收進來)

| 階段 | 輸入 | latent | 輸出 | 多出來的東西 |
