# 07 · 白話使用說明 — 給「有原始資料的老師」

> 用最白話的方式說明:**這個資料夾是什麼、你要做什麼、按什麼順序、會得到什麼。**
> 不需要懂機器學習。看完這頁,你就知道怎麼把你的資料接上我們做好的 PCA / AE / VAE。

---

## 這個資料夾在做什麼(一句話)

> 我們做好了一套程式,能**把每個城市格子的一堆數字,壓成 2 個數字,再還原回去,甚至生成全新的格子**。
> 你負責「把原始資料整理成它看得懂的表格」,剩下的它自己跑。

---

## 你只要做三件事

### 第 1 件:把原始資料整理成「一張表」
- 規格寫在 **`06_INTERFACE_HANDOFF.md`**(那份是「契約」,照著做就對了)。
- 簡單說:**一列代表一個 50 公尺的格子**,每列填 9 個數字(樓地板面積、覆蓋率、平均高度、五種房型比例、主導機能比例),再加上格子的位置(window/row/col)。
- **重點:給原始的真實數字就好(真的公尺、真的平方公尺),不要自己換算或縮放**——程式會自己處理。空格子就把數字全填 0。
- 存成 `cells.parquet`。

### 第 2 件:把表放到對的位置(或告訴程式在哪)
- 放到 `v03/cache/cells.parquet`,或跑的時候用 `--data 你的路徑`。

### 第 3 件:照順序跑三個程式
```
cd teaching/pca_ae_vae/code
pip install -r requirements.txt        # 第一次才要,裝套件

cd simple        # 兩個版本:simple(精簡)或 detailed(逐行詳解),結果一樣
python pca.py                          # 壓縮法一:PCA(秒出)
python ae.py                           # 壓縮法二:AE(會訓練,幾分鐘)
python vae.py                          # 壓縮法三:Beta-VAE(會生成新格子)
```

就這樣。每個程式會印出「壓得好不好」的數字,並在 `outputs/` 存一張圖。
每個檔都是**獨立完整**的,讀一個檔就看得到全部步驟。

---

## 你會得到什麼

| 跑完 | 你會看到 | 在哪 |
|---|---|---|
| `pca.py` | 重建誤差數字 + 一張 latent 散點圖 | `outputs/pca_latent.png` |
| `ae.py` | 訓練過程(誤差往下掉)+ latent 圖 + 模型檔 | `outputs/ae_latent.png`, `outputs/ae.pt` |
| `vae.py` | latent 圖 + **生成的全新格子**(8 筆) | `outputs/vae_latent.png`, `outputs/vae_generated.npz` |

- **latent 散點圖**:每個城市格子被壓成的 2 維座標。這張圖可以交給「分析線」老師上色、看分群。
- **生成**:VAE 能無中生有產生新的格子數字,交給「生成/渲染線」變成新城市。

---

## 「我訓練跑太久 / 跑壞了」怎麼辦(安全網)

我們**附了訓練好的模型**。任何一步卡住,改一個字就好:把 `ae.py` / `vae.py` 檔案頂端的

```
USE_PRETRAINED = False     →     USE_PRETRAINED = True
```

存檔再跑,它就**不訓練、直接用我們訓好的模型**,照樣走到生成。

> 反過來,你想用**你自己的新資料**重新訓一份「官方預訓練檔」給學生用:
> 確認 `USE_PRETRAINED = False`、`DATA` 指到你的資料,跑 `python ae.py` / `python vae.py`,
> 再把 `outputs/` 裡的 `ae.pt` / `vae.pt` 複製到 `pretrained/` 覆蓋即可(細節見 `code/pretrained/README.md`)。

---

## 三個程式到底差在哪(白話)

| 程式 | 它做的事 | 一句話 |
|---|---|---|
| **PCA** | 用數學一步把資料壓扁 | 最快、最簡單,不用訓練 |
| **AE** | 讓一個小神經網路「學」怎麼壓 | 壓得比 PCA 好,但不會生成 |
| **VAE** | AE 再升級,壓出來的空間很整齊 | **會生成全新資料** |

想懂更多技術細節,看同資料夾:
- `01_CONTEXT.md`(三者關係)、`02_DATAFLOW.md`(資料怎麼流)、
- `03_PIPELINE.md`(踩雷排解)、`04_ARCHITECTURE.md`(模型細節)、
- `05_TEACHING_GUIDE.md`(上課逐段講法)。

## 常見狀況

| 你遇到 | 處置 |
|---|---|
| 程式說「缺 channel 欄位」 | 表格欄名沒對齊,照 `06_INTERFACE_HANDOFF.md` §3 改 |
| 程式說「有 NaN」 | 空格子請把數字填 0,不要留空白 |
| 圖沒出來 | 沒裝 matplotlib(數字還是有印);`pip install matplotlib` |
| 訓練太久 | 把檔頂 `USE_PRETRAINED = True` 用現成模型 |
| 結果看不懂城市意義 | 那是「分析線」老師的事,本資料夾只負責壓縮/生成技術 |
