# PCA → AE → VAE 教學包(助教技術線)

> DigitalFUTURES 2026 · 都市利害關係人工作坊 · 技術組(助教)
> 本包**只負責表示學習(representation learning)技術層面**:PCA、Autoencoder(AE)、
> Variational Autoencoder(VAE)。城市資料的 stakeholder 解讀由另一位老師負責,本包不碰。
> 我們借用城市 grid 資料當「跑例」,目的是讓學生親手把高維資料壓成低維、再生成回來。

## 這份教學包要回答的三個問題

1. **怎麼把一筆超高維的城市資料壓成幾個數字?**(PCA)
2. **神經網路怎麼做同一件事,而且做得更好?**(AE)
3. **怎麼讓壓出來的空間「可以抽樣生成新資料」?**(VAE)

## 模型選型現況(2026-06-20 定案:Beta-VAE)

VAE 採用**連續 Beta-VAE**(而非離散 VQ-VAE):它是 AE 的直接延伸、只加 β 一個旋鈕、能直接抽樣生成,
符合「每階只加一個概念」;VQ-VAE 在逐 cell 向量上會退化成 K-means、且需另訓自迴歸先驗才能生成,
不適合這條 2 小時教學線(理由詳見 `05_TEACHING_GUIDE.md` §7)。
→ `code/{simple,detailed}/vae.py` 已實作並實測(N=5785 上 val 重建誤差 ~0.14、可生成)。

## 全包共用的「跑例」設定(所有文件一致)

| 符號 | 值 | 意義 |
|---|---|---|
| `N` | **5,785** | 非空 cell 數(整份資料的樣本數) |
| `C` | **9** | 每個 cell 的 channel 數(輸入維度) |
| `k` / `L` | **2** | 壓縮後的維度(latent;設 2 是為了畫得出來) |
| grid | **24 窗 × 20×20** | 影像版用例(conv 變體用) |

> 9 個 channel:`gfa, coverage, mean_h, sh_house, sh_slab, sh_tower, sh_large, sh_mid, dom_sem_share`
> (細節見 `02_DATAFLOW.md`。學生不需要懂這些欄位的城市意義——那是另一位老師的事;
> 對技術線而言它們就是「9 個數字」。)

## 一句話總綱

> **PCA 用數學一步把資料轉好;AE 讓神經網路學著壓;VAE 再要求壓出來的空間長得像一張可以亂槍打鳥也能生成的地圖。** 三者是同一件事的三個版本:壓縮 → 學習式壓縮 → 可生成的學習式壓縮。
