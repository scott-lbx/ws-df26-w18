# 教學大綱 · 用神經網路延伸「權力→形態」分析
### 給城市規劃學生的潛空間入門(概念與啟發,非程式實作)

> **對象**:已學過 `05_Shanghai Power to Form Students`、但 Python 還不熟的規劃學生。
> **目標**:理解「怎麼把 NN 接進你們已經會的都市分析流程」——重觀念、重直覺、重圖解,不帶大家敲程式。
> **一句話**:05 教你「權力如何重寫城市形態」;這份教材教你「用 NN 把那套形態變成**可壓縮、可比較、可生成**的空間」。
>
> 本檔是**簡報腳本**:每個 `##` = 一張(或一組)投影片。`【視覺】`= 該頁要放的圖(真實結果圖在 `out/figs/`,標「示意」者為簡報要新畫的概念圖)。`【講稿】`= 口說重點。

## 0 · 開場:規劃師為什麼要碰神經網路?

**【直覺】** 你們已經會看容積率、覆蓋率、天際線。問題是——當城市有 **9 個形態指標、幾千棟樓、十幾個街區、五種權力情形**,人腦一次看不完。NN 的角色不是取代規劃判斷,而是**把高維形態壓成一張看得懂的圖**,讓你繼續用專業判斷。

**【視覺】** 一張對比:左=規劃師手動看 9 張分佈圖(眼花);右=壓成一張 2D 潛空間散點(一眼看出族群)。(示意)

**【講稿】**
- NN = 「形態的壓縮器 + 生成器」,不是黑魔法。
- 規劃知識仍是主角:NN 給地圖,你來讀「這代表什麼權力邏輯」。

## 1 · 從 05 流程出發:NN 在哪裡介入?

**【回顧 05 流程】**
```
上海多源資料 → 拼接(01)→ 角色映射(02)→ 只調高度情景(03)
   → 權力算子四體制(04)→ 3D 量體/OBJ(05)
```
每個街區、每種體制,05 最後都能算出 **9 個形態指標**(`measure.diagnose`):
`far 容積率 · coverage 覆蓋率 · h_mean/h_max 高度 · h_cv 高度不均 · grain 顆粒 · slender 瘦高 · concentration 集中度 · n 棟數`。

**【NN 介入點】** 就接在 05 的**輸出**後面——不動 05 一行:
```
05 產出(每城×體制 → 9 指標 / 每棟樓 → 多源特徵 / 整城 → 高度影像)
        │
        ▼  ← NN 從這裡接手
   壓縮成潛空間 → 分析族群 → 生成新方案
```

**【視覺】** 流程長條圖:05 五步(藍)＋ 右端接三個 NN 方塊「壓縮/分析/生成」(橘)。(示意)

**【講稿】**
- NN **不改資料來源**:讀的就是 05 拼接好的 `buildings.parquet` 和 9 指標。
- 三種資料粒度、三種切入:
  - 每棟樓 → 一列特徵向量(表格)
  - 整座城 → 一張高度影像(給 CNN)
  - 每城×體制 → 9 維形態(接權力分析)

## 2 · 三代方法的差異:查表 → 非監督 ML → 神經網路

**【核心對照表】**

| 世代 | 方法 | 怎麼運作 | 規劃類比 | 會什麼 / 不會什麼 |
|---|---|---|---|---|
| **規則** | Lookup table | 人寫死對照規則 | 查土地使用分區規範 | 透明可控;但**規則得人訂**,不會自己發現結構 |
| **非監督 ML** | PCA / t-SNE / Isomap | 數學找資料主結構 | 把調查表自動歸類 | 找族群、看結構;多數**不能還原/生成** |
| **神經網路** | AE / VAE / CNN | 網路**學**壓縮與重建 | 學徒臨摹再默寫、甚至創作 | 能壓、能**重建、能生成**;較黑箱、需訓練 |

**【一句話差異】**
- **Lookup(規則)**:你告訴電腦「商業=開發商」。→ 05 的 `shanghai_lookup.yaml` 就是這個。
- **非監督 ML**:你不給答案,電腦自己說「這些城長得像、那些不像」。
- **神經網路**:電腦不只分類,還能「**造一個沒看過但合理的城市**」。

**【視覺】** 三格漫畫:①查字典 ②把便利貼自動分堆 ③畫出新城市。(示意)

**【講稿 · 誠實補充】**
- AE/VAE/CNN 嚴格說是**自監督**(答案=自己這張圖,不需人工標註),不是傳統「監督」。對規劃學生只要記:**它們會生成,前兩代不會**。
- 越往右:能力越強、越不透明。規劃用途決定選哪代,不是越新越好。

## 3 · 非監督 ML 原理:PCA / t-SNE / Isomap(直覺版)

> 共同任務:把**高維**(9 維或 16 維)壓到 **2D** 好看。差別在「保留什麼」。

### 3.1 PCA —— 找城市變化的「主軸」
**【直覺】** 一群城市在 9 維空間裡是一團雲。PCA 問:「這團雲**最長的方向**是哪條?」那條就是 **PC1**——多半是「開發強度/資本 ↔ 細粒自建」。第二長的是 PC2。用這兩條當新座標軸。

**【視覺】** 一團斜橢圓點雲 + 畫出最長軸 PC1、次長軸 PC2。(示意) ＋ 真實載荷圖 `out/figs/04_cluster_interpret.png`(左半)。

**【規劃意涵】** PC1「47% 方差」= 城市差異近一半能用**單一強度軸**解釋。軸**可解讀**:負向=高容積高聳密集(資本),正向=瘦長細碎多棟(自建)。

### 3.2 t-SNE —— 只在乎「誰跟誰是鄰居」
**【直覺】** 不管全域距離,只把**原本相近的點**在 2D 裡也擺近。像把班上同學按「常一起玩」分小圈圈——圈內對,但**圈跟圈之間的距離沒意義**。

**【視覺】** 同一份點,t-SNE 擠出好幾個緊密小團。(示意) ＋ 真實 `out/figs/01_method_compare.png`(中欄)。

**【規劃意涵】** 適合**看聚類**(哪些城×體制自成一群),但別解讀「兩群離多遠」。參數(perplexity)換一下圖就變,**不穩定**。

### 3.3 Isomap —— 把摺起來的紙攤平
**【直覺】** 資料像一張捲起來的紙,直線距離會「穿牆」。Isomap 沿著**紙面**量距離(測地線)再攤平,保留全域彎曲結構。

**【視覺】** 瑞士捲被攤平成長條的示意圖。(示意) ＋ 真實 `01_method_compare.png`(右欄,Isomap)。

**【規劃意涵】** 想保「整體流形結構」用它;和 t-SNE 一樣**沒有可解讀的軸、不能逆回原始城市**。

**【本節小結表】**

| | 保全局 | 可解讀軸 | 能逆回/生成 | 何時用 |
|---|:-:|:-:|:-:|---|
| PCA | ✔ | ✔ | ✔(線性) | 要解釋、要重建 |
| t-SNE | ✘ | ✘ | ✘ | 只看聚類 |
| Isomap | ✔ | ✘ | ✘ | 看流形結構 |

## 4 · 神經網路原理:AE / VAE /(CNN)(以 AE、VAE 為主)

### 4.1 AE 自編碼器 —— 學徒「臨摹→默寫」
**【直覺】** 給網路一張城市形態,逼它先**壓成幾個數字(瓶頸)**,再**只憑那幾個數字畫回原樣**。若能畫回來,代表那幾個數字抓住了精華。中間的瓶頸 = **潛碼(latent)**。

**【視覺】** 沙漏圖:寬(9維)→ 窄(2維瓶頸)→ 寬(9維);標「編碼器/潛碼/解碼器」。(示意)

**【規劃意涵】** 非線性壓縮 → 同樣 2 維,**重建比 PCA 準很多**(結果見 §5)。潛碼=「城市形態的濃縮 DNA」。

### 4.2 VAE 變分自編碼器 —— 學會「風格」才能創作
**【直覺】** AE 只會默寫看過的;VAE 更進一步,把潛空間規範成一團**標準常態雲 N(0,I)**。於是你可以**隨手在雲裡點一下、解碼出一個沒看過但合理的城市**——這就是生成。

**【視覺】** 左:AE 潛空間有破洞(點與點間是空的,踩進去解出亂碼);右:VAE 潛空間填滿、連續(隨處可採樣)。(示意)

**【規劃意涵】** VAE = **會生成的規劃引擎雛形**。想問「若把這塊地推向某種形態,長怎樣?」——在連續潛空間插值/採樣即可。代價:重建略遜 AE(多了規範化)。

**【關鍵配角:β 與 posterior collapse】**
- `total = 重建 + β × KL`。β 太大 → 潛碼被壓垮失效(**posterior collapse**,潛空間退化)。用 **β 退火**(先學重建再慢慢規範)避免。
- **【視覺】** `out/figs/02_ae_vae_loss.png`——(a) 過擬合、(b) 損失拆解、(c) 塌縮 vs 退火。

### 4.3 CNN(Conv-VAE)—— 看空照圖的「紋理」
**【直覺】** 前面把每棟樓當一列數字,丟了**空間排列**。把整座城燒成一張**高度影像**(每格=建築高度),用卷積網路像看空照圖一樣讀「街廓紋理、疏密」。

**【視覺】** 一張真實高度圖(陸家嘴,亮點=超高層)＋ 切成小 patch。(見 NB1/NB3 輸出) ＋ Conv-VAE 生成的高度紋理。

**【規劃意涵】** urban form 最自然的 NN 表示。教學重點:**換表示(表格→影像)、換架構(MLP→CNN),模型看到的東西完全不同**。誠實邊界:高度圖 86% 空白、樣本少 → 本例僅示意,潛碼部分塌縮。

## 5 · 訓練結果(真實數據,直接讀圖)

### 5.1 重建:AE 完勝、加維才追平
**【視覺】** `out/figs/03_recon_compare.png`

| 方法 | 重建誤差 MSE(越低越好) |
|---|---|
| PCA 壓到 2 維 | 0.329 |
| PCA 壓到 4 維 | 0.104 |
| **AE 壓到 2 維** | **0.061** |
| **AE 壓到 3 維** | **0.033** |
| VAE 壓到 2 維 | 0.241 |

**【講稿】** AE 用 **2 維**就贏過 PCA 用 **4 維**——非線性瓶頸更省維。這是「NN 比統計法強在哪」最有感的一格。

### 5.2 AE/VAE 怎麼訓練出來的
**【視覺】** `out/figs/02_ae_vae_loss.png`
**【講稿】** (a) 沒正則的 AE 會**背答案**(驗證變差);(b) VAE 重建與 KL 此消彼長;(c) β 退火避免潛碼塌縮。→ 訓練不是按一下,是**調正則、調 β**。

### 5.3 群聚:資料自己會不會分出「權力體制」?
**【視覺】** `out/figs/08_cluster_vs_regime.png`

| 潛空間 | ARI(復原手動 regime) | silhouette(群多緊) |
|---|---|---|
| 原始 9 維 | **0.70** | 0.32 |
| VAE-2 | 0.56 | **0.58** |
| PCA-2 | 0.55 | 0.49 |
| AE-2 | 0.34 | 0.55 |

**【講稿 · 對規劃最重要的一格】** 不給任何標籤,KMeans 只看形態就**大致復原了 05 手訂的五種權力體制(ARI 0.70)**→ 代表「這些 regime 不是憑空設的,**有形態資料支撐**」。這就是 NN/資料驅動**有別於手動 lookup** 的價值:客觀檢驗你的規則,甚至發現新族群。

### 5.4 誰在成簇:體制,不是城市家族
**【視覺】** `out/figs/04_cluster_interpret.png`
**【講稿】** silhouette 按**體制**(0.24–0.42)遠高於按**城市家族**(≈0)。→ 同一套權力算子把不同城推向**一致方向**;城市原本的類型反而被打散。權力 > 地方性。

### 5.5 生成能力:只有 VAE 真的會「造城」
**【視覺】** `out/figs/06_gen_capability.png` ＋ `out/figs/07_gen_cloud.png`

| 方法 | 能生成? | 生成有多真(越低越像) | 守物理約束 |
|---|:-:|---|---|
| **VAE** | ✔ 先驗採樣 | **1.03** | **100%** |
| PCA | ~ | 1.40 | 97% |
| AE | ~ 無先驗 | 2.11 | 93% |
| t-SNE / Isomap | ✘ | — 不能生成 — | — |

**【講稿】** **能不能生成 = 有沒有 decoder。** t-SNE/Isomap 只會投影、回不去,所以**不能生成**。VAE 有先驗、生成最真、插值最連續。

### 5.6 權力重新分配 = 潛空間裡的位移
**【視覺】** `out/figs/05_regime_signature.png`
**【講稿】** 每種體制 = 把城市從基線**推向某個方向**的向量:
- 開發商 → 拔高塔化(`h_mean`↑)
- 政府 → 向公共重心收攏(`concentration`↑)
- 居民自建 → 細粒化(`grain`↓、棟數↑)
- 共享 → 釋放開放地面(`coverage`↓)

「權力重寫城市」不再只是文字描述,而是**可量化、可比較的位移**。

## 6 · 綜合比較:哪個工具解哪種規劃問題

**【總表】**

| 規劃問題 | 最佳工具 | 為什麼 |
|---|---|---|
| 想要**透明可控**的規則 | Lookup table | 你訂、可審、可辯 |
| 想**把城市分族群、看結構** | PCA / UMAP / Isomap | 非監督找結構 |
| 想要**可解讀的主軸** | PCA | 軸=特徵線性組合 |
| 想**高效壓縮/重建** | AE | 非線性瓶頸最省維 |
| 想**生成新方案、做情景** | **VAE** | 連續潛空間可採樣/插值 |
| 想看**空間紋理** | CNN(Conv-VAE) | 卷積讀街廓排列 |

**【視覺】** 光譜圖:左「透明·規則」→ 右「強大·生成」,標各方法位置;下方箭頭「越右越能生成,越左越可控」。(示意)

**【一句總結】** 沒有最好的方法,只有**對應規劃問題的方法**:要可控用規則,要看結構用非監督,要生成/做方案用 VAE。

## 7 · 對規劃的啟發 & 誠實邊界

**【啟發】**
1. NN 把「權力→形態」從**描述**升級成**可量化、可比較、可生成**的空間。
2. 資料驅動的群聚能**檢驗人訂規則**(regime ARI 0.70),甚至提出人沒想到的族群。
3. VAE 的連續潛空間 = **情景生成器**雛形:規劃師出概念,NN 出候選形態。

**【誠實邊界(務必對學生說)】**
- 樣本小(60 樣本 / 稀疏高度圖)→ AE/VAE/CNN 皆**教學演示**,非嚴謹預測。
- 體制簽名是**算子設定的必然結果**(教學語言),不是真實城市的實證發現。
- NN 是**放大鏡不是水晶球**:給結構與候選,價值判斷仍是規劃師的責任。
